 Bot general testing checklist:
                                                                                                                                                                                                                        
  Tasks:
  - Create a task (check it asks for urgency if you don't provide it)
  - List open tasks
  - List completed tasks
  - Complete a task by name
  - Reopen a completed task
  - Update a task (title, urgency, due date)
  - Delete a task (should ask for confirmation)

  Suppliers:
  - Create a supplier
  - List all suppliers
  - Update a supplier's contact info
  - Delete a supplier with no issues
  - Try deleting a supplier that has open issues (should block)

  Issues:
  - Create an issue (check it asks for product name if missing)
  - List all issues
  - List issues filtered by supplier name
  - List action items for a specific issue
  - Add an action item (without linked task)
  - Add an action item with a linked task (should ask urgency + suggest description)
  - Resolve an issue
  - Reopen a resolved issue

  Edge cases:
  - Fuzzy name matching — use partial/misspelled names
  - Send a message with multiple requests in one sentence
  - Send something completely off-topic (should stay in scope)
  - Check conversation memory — refer to something from earlier in the chat

  Website sync:
  - Do something via bot, verify it shows on the website
  - Do something on the website, verify bot sees it
